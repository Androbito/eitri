# Schema baselines

`1.db` is the schema at version 1, generated by `./gradlew :storage:generateMainServanteDatabaseSchema`
and committed on purpose. `check` verifies every migration against it, which is what makes the promise
in `docs/adr/0005` real: a change that would drop a column or a table from a user's audit log fails the
build instead of reaching a release.

When the schema changes, add a numbered `.sqm` migration beside the `.sq` files, then regenerate the
baseline for the new version with the same task and commit both. Never edit a committed `.db`, and never
delete one to make the verification pass.
