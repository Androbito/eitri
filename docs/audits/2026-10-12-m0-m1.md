# Mobile quality audit: Servante itself (desktop, JVM, 2026-10-12)

End of M0 and M1, run with the `mobile-quality-audit` skill's checklists against what exists. Servante
is a desktop app, so the checklists that assume a phone are mapped: process death becomes window close
and crash, battery becomes long-running work on the UI thread, Play Data Safety becomes the privacy
registry.

## Verdict

**Not ready, and not claimed to be.** What exists is sound and tested: 204 tests pass, ktlint and detekt
are clean, every product rule that can be expressed in code is expressed in a type. What does not exist
is the entire user interface, because Compose Multiplatform cannot be resolved in the environment this
was built in. Nothing can be released until that is built and seen.

Three findings below are real work, not environment artefacts. Everything else passed with evidence.

## P0

None. There is no release to be unsafe.

## P1

| # | Area | Finding | Evidence | Fix |
| --- | --- | --- | --- | --- |
| 1 | Compatibility | The Windows secret store is native code no runner here can execute, so it is unverified. A Windows user could find that saving an API key silently fails | `storage/.../WindowsCredentialManagerSecretStore.kt`, a JNA mapping of `CredWriteW`; its tests cover the macOS and Linux stores only | CI's Windows job exists for this. Add a test tagged to that runner that round-trips a value through the real Credential Manager, and treat a red Windows job as blocking |
| 2 | Concurrency | `JvmProcessRunner.stream` joins its reader threads on a daemon thread and closes the flow from there. The flow completes correctly in the tests, but cancellation during a long Gradle build is exercised only by the timeout test | `storage/.../JvmProcessRunner.kt:79`, `JvmProcessRunnerTest` has no cancellation test | Add a test that cancels the collecting scope mid-stream and asserts the process is gone. Do it before M2, which is the first tool to stream a real build |
| 3 | Localisation | French is complete and compiles nowhere, so no French string has ever been rendered. Long German-style compounds are not the risk here; the risk is that `welcomeBody` and `privacyBody` are long sentences that may not fit the drawn layout at 200% text scale | `ui/.../FrenchStrings.kt`, no screen built | Check both languages at 100% and 200% scale as the first thing after the UI compiles, and before any screenshot goes into `design/implemented/` |

## Passed checks, with evidence

| Area | Evidence |
| --- | --- |
| Security: secrets never on disk | `Secret` is a value class whose `toString` is `Secret(hidden)`; `SecretTest` asserts a holder object does not print it. `ProcessCommand.describe()` excludes stdin and is asserted to. No secret reaches the database: the only thing stored is the name of a key, in `SecretKeyIndex` |
| Security: secrets never in logs | Process failures are reported with the command description and the exit code, never the captured output: `describeFailure` in `MacOsKeychainSecretStore.kt`. The Markdown export is asserted not to contain the fixture password |
| Security: no telemetry, no backend | `NetworkDestinations` is the whole list of reachable hosts, seven plus the user's own AI endpoint, and `NetworkDestinationsTest` asserts the exact set. There is no HTTP client in the codebase yet, so there is nothing that could call anywhere else |
| Security: minimal permissions, in context | Reads by default. The one write path is `WriteGate`; `GatedWriterTest` asserts a declined request writes nothing and records nothing |
| Offline-first | Nothing in M0 or M1 needs the network. The Play certificate is the only networked value and its absence is an unavailable cell with a reason, not an error |
| Lifecycle, data loss | Writes go to a temporary sibling and are moved into place, so an interrupted write cannot leave a half-written file: asserted by `no temporary file is left behind` and by the partial-failure test |
| Concurrency: no I/O on the caller's thread | Every I/O entry point takes a `CoroutineDispatcher` and defaults to `Dispatchers.IO`; tests inject `UnconfinedTestDispatcher` |
| Concurrency: determinism | Time is injected everywhere through `kotlin.time.Clock`; `FixedClock` is in the shared test fixtures. Locale and time zone are pinned by the test task |
| Compatibility: defined minimum | JVM 21 toolchain declared in one convention plugin. Gradle, Kotlin and every library version verified against its publishing repository on the date in `gradle/libs.versions.toml`, not remembered |
| Design system: no hard-coded values | Colours, type and spacing exist only as tokens in `ui/theme`, translated one to one from `design/tokens.md`. No feature code exists yet to violate it, so this is a pass to re-check at the end of M2 |
| Privacy: the list cannot drift | The privacy table renders from `NetworkDestinations` and `StringsTest` asserts every registered destination has a reason and a timing in both languages, so adding a host without explaining it fails the build |
| Testability | 204 tests. The pyramid is as `docs/adr/0008` maps it: unit tests on rules and parsers, integration tests against a real in-memory SQLite database and real processes, end-to-end over the fixture project with the real detector |

## Not verifiable from the code

- Real start-up time, memory and rendering performance: no app to measure. Measure once the shell runs,
  on the slowest of the three systems.
- Keyboard navigation and focus order: no screens.
- The AppImage, DMG, MSI and DEB installers: the workflows are written and have never run.

## What was fixed during this audit

Nothing was deferred from it. Three defects found while auditing were fixed in place and are in the
commits: the clean-up path in `GatedWriter` that threw over the real failure, the false "Play does not
know this key" finding for the upload key, and the keystore format being reported as whichever JDK
provider opened the file rather than what the file is.
